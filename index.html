PhishGuard — Self-Hosted Email Phishing & BEC Detection Engine

An industrial-grade, self-hosted, offline-first email security engine that ingests messages (.eml, raw text, or live IMAP) and executes 9 transparent analyzers to generate weighted, auditable verdicts with detections-as-code rules.

9 Analyzers: SPF/DKIM/DMARC auth, domain aging, NLP/content, attachments, BEC baseline, and sandboxing
Dual Interface: High-performance Python CLI and Next.js 14 + FastAPI single-port web control plane
SIEM Integration: Syslog export (CEF / JSON) & Webhooks with automated post-delivery triage
Python 3.10+ FastAPI Next.js 14 IMAP Fetcher SIEM Export (CEF) Threat Feeds
python // phishguard_pipeline.py Detection Engine 
# PhishGuard — 9-Layer Inbound Mail Triage
from phishguard.pipeline import analyze_email
from phishguard.mail import RFCParser

msg = RFCParser.from_eml("suspect_invoice.eml")
report = analyze_email(msg, enable_enrichment=True)

if report.risk_score >= 75:  # Malicious / Phishing
    report.export_to_siem(format="CEF")
    report.trigger_quarantine_action()
